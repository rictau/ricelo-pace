Formula, Excel & JS

Any Race Pair

x = 1.06 + w · max(0, 0.5413 − 0.1002 · ln(max(10, V)))
T2 = T1 · (D2 / D1)x

w = (ψ(D2) − ψ(D1)) / ln(D2 / D1), where ψ(D) = 0 for D ≤ 5 km and 0.030215 · ln(D / 5)3.8427 up to 42.195 km (plus ln(D / 42.195) above marathon).

  • HM ↔ FM 0.624
  • 10K ↔ FM 0.380
  • 5K ↔ FM 0.260
  • 10K ↔ HM 0.154
  • 5K ↔ HM 0.085
  • 5K ↔ 10K 0.011

Current Pair Shortcut (HM → FM, w = 0.624)

x = 1.06 + max(0, 0.3377 − 0.0625 · ln(max(10, V)))
TFM = THM · 2x

Excel / Sheets (Any Race Pair, up to FM)

A2 = race time, B2 = from km, C2 = to km, D2 = km/week 
=IF(B2=C2, A2, A2 * (C2/B2)^(1.06 + (0.030215 * (LN(MAX(5, C2)/5)^3.8427 - LN(MAX(5, B2)/5)^3.8427) / LN(C2/B2)) * MAX(0, 0.5413 - 0.1002 * LN(MAX(10, D2)))))

Excel / Sheets (HM → FM Shortcut)

A2 = Half time, B2 = km/week 
=A2 * 2^(1.06 + MAX(0, 0.3377 - 0.0625 * LN(MAX(10, B2))))

JavaScript (Any Distance, incl. Ultras)

function riceloPace(t1Sec, d1Km, d2Km, vKmWk) {
  const L = Math.log(42.195 / 5), g = 2.8427;
  const psi = d => d <= 5 ? 0 : d < 42.195
    ? (L / (g + 1)) * (Math.log(d / 5) / L) ** (g + 1)
    : L / (g + 1) + Math.log(d / 42.195);
  const w = d1Km === d2Km ? 0 : (psi(d2Km) - psi(d1Km)) / Math.log(d2Km / d1Km);
  const x = 1.06 + w * Math.max(0, 0.5413 - 0.1002 * Math.log(Math.max(10, vKmWk)));
  return t1Sec * (d2Km / d1Km) ** x;
}
